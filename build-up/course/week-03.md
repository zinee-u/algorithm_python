<details><summary>막혔을 때만: 힌트와 해설</summary>

1. 최단 거리나 가능한 경우의 수를 구하는 문제가 아닙니다. 정해진 위치 이동을 그대로 재현하는 구현·시뮬레이션입니다. 먼저 3 × 3 배열에 1부터 9까지 적고 시계 방향 45도 뒤의 위치를 손으로 확인해 보세요.
2. 네 줄은 동시에 이동합니다. 현재 배열에 바로 덮어쓰면 나중에 옮겨야 할 원래 값이 사라집니다. 이전 배열에서 읽고, 행마다 복사한 새 배열에 쓰세요. matrix[:]는 안쪽 행을 공유하지만 [row[:] for row in matrix]는 각 행을 따로 복사합니다.
3. mid = n // 2, steps = (d // 45) % 8로 두세요. 한 단계마다 after[i][mid] ← current[i][i], after[i][n-1-i] ← current[i][mid], after[mid][n-1-i] ← current[i][n-1-i], after[i][i] ← current[mid][i]를 적용합니다. 단계가 끝난 뒤 current = after로 교체합니다.

문장에서 정해진 이동 규칙과 “동시에”가 보이면 좌표 변환을 한 단계씩 시뮬레이션하는 방법을 떠올립니다. 0부터 세는 인덱스에서 주 대각선은 (i, i), 가운데 열은 (i, mid), 부 대각선은 (i, n - 1 - i), 가운데 행은 (mid, i)입니다. 시계 방향을 확인하려면 모서리 하나를 추적하세요. 왼쪽 위 (0, 0)는 (0, mid)로, 오른쪽 위 (0, n - 1)는 (mid, n - 1)로 갑니다.

매 단계 current는 읽기 전용으로 사용하고 after에만 씁니다. after를 [row[:] for row in current]로 만들면 움직이지 않는 칸도 보존되며, 정수 배열이므로 각 행을 복사하는 것으로 충분합니다. after = current[:]는 행을 공유하므로 after의 칸을 바꾸면 current의 같은 칸도 바뀌어 동시 갱신이 깨집니다. 한 단계의 네 대입을 모두 마친 뒤 current = after로 교체합니다.

반복문 한 번은 시계 방향 45도 회전입니다. turns = d // 45는 각도를 45도짜리 횟수로 바꾸며, 양수는 시계 방향, 음수는 반시계 방향 횟수를 뜻합니다. 예를 들어 90 // 45 = 2, -45 // 45 = -1입니다. d는 45의 배수이므로 나눗셈 결과가 정확한 정수입니다.

45도씩 8번이면 360도로 제자리입니다. steps = turns % 8은 같은 최종 배열을 만드는 시계 방향 횟수를 0~7 사이로 바꿉니다. 파이썬에서 양수 8로 나눈 나머지는 0~7이며, -1 = (-1) × 8 + 7이므로 -1 % 8 = 7입니다. 따라서 반시계 45도 한 번과 시계 45도 일곱 번의 최종 배열이 같습니다. 중간 이동 경로는 다릅니다. -90도는 시계 6번, -315도는 시계 1번, 360도와 -360도는 0번입니다. 네 줄이 있다고 주기가 4인 것은 아닙니다. 왼쪽 위 값은 왼쪽 위 → 위 → 오른쪽 위 → 오른쪽 → 오른쪽 아래 → 아래 → 왼쪽 아래 → 왼쪽 → 왼쪽 위 순서로 이동하여 8번 만에 제자리로 돌아옵니다.

range(steps)는 0부터 steps - 1까지의 정수를 차례로 주므로 본문이 steps번 실행됩니다. range(0)이면 본문은 한 번도 실행되지 않습니다. for _ in range(steps)의 _는 반복 번호를 사용하지 않겠다는 관례적인 변수 이름이며, 특별한 회전 연산자가 아닙니다. 반복 번호 대신 i를 써도 회전 동작은 같습니다. 중심 칸은 네 줄이 겹치지만 항상 같은 원래 값을 쓰므로 안전합니다.

steps를 k라 하면 시간 복잡도는 O((k + 1) × n²), 공간 복잡도는 O(n²)입니다. k가 최대 7이므로 이 문제에서는 시간도 O(n²)로 볼 수 있습니다.

원문에 제출할 때는 T번 n, d와 n개의 행을 읽고 이 함수를 호출한 뒤 각 행을 print(*row)로 출력하는 입출력 코드를 덧붙이면 됩니다.

```python
def solution(matrix, d):
  current = [row[:] for row in matrix]
  n = len(current)
  mid = n // 2
  steps = (d // 45) % 8

  for _ in range(steps):
    after = [row[:] for row in current]
    for i in range(n):
      after[i][mid] = current[i][i]
      after[i][n - 1 - i] = current[i][mid]
      after[mid][n - 1 - i] = current[i][n - 1 - i]
      after[i][i] = current[mid][i]
    current = after

  return current
```

1. 한 연산 안의 이동은 동시에 일어나지만, 여러 연산은 순서대로 일어납니다. 겹친 영역이 있으므로 모든 각도를 하나로 합치거나 매번 최초 board에서 값을 읽으면 안 됩니다.
2. 부분 배열 안에서는 좌표가 0부터 size - 1까지라고 생각하세요. 그 안의 (r, c)는 전체 패널의 (top + r, left + c)입니다. 부분 배열을 복사해 원래 값을 보관한 뒤, 이 좌표 변환을 거쳐 결과에 쓰면 됩니다.
3. result = [row[:] for row in board]로 시작합니다. 각 연산을 (d // 45) % 8번 반복하고, 매 45도 직전에 before = [row[left:left + size] for row in result[top:top + size]]를 만드세요. before에서 네 줄의 값을 읽고 result[top + r][left + c]에만 쓴 다음 다음 단계로 넘어갑니다.

기본 문제의 한 단계 회전 함수를 부분 배열에 적용하는 구현·시뮬레이션입니다. 두 종류의 순서를 구별해야 합니다. 한 45도 단계 안에서 네 줄을 옮기는 것은 동시 갱신이므로, 쓰기 전에 해당 부분 배열의 값을 before에 모두 복사합니다. 반면 operations에 담긴 여러 연산은 앞 연산을 끝낸 뒤 그 결과에 다음 연산을 적용합니다. 특히 겹친 영역은 연산 순서에 따라 값이 달라지므로 각도를 무조건 합칠 수 없습니다.

전체 결과 배열 result를 행마다 복사하고, 각 연산의 steps = (d // 45) % 8을 구합니다. 매 단계 before를 현재 result의 부분 배열에서 새로 만듭니다. mid = size // 2라고 하면 로컬 좌표 (i, i) → (i, mid), (i, mid) → (i, size - 1 - i), (i, size - 1 - i) → (mid, size - 1 - i), (mid, i) → (i, i)를 사용합니다.

before는 로컬 좌표로 읽고, result에 쓸 때만 행에 top, 열에 left를 더합니다. 예를 들어 result[top + i][left + mid] = before[i][i]입니다. 오프셋은 한 번만 더해야 합니다. before의 각 행은 슬라이스로 새로 만들었으므로 result에 써도 before는 바뀌지 않습니다. 네 줄에 해당하는 칸만 쓰므로 그 밖의 값은 자동으로 보존됩니다.

전체 행·열 수를 R, C, 각 연산의 크기를 s_j, 정규화한 회전 횟수를 k_j라 하면 시간 복잡도는 O(RC + Σ(k_j × s_j²)), 공간 복잡도는 O(RC + max(s_j²))입니다. 연산이 없으면 시간·공간 모두 초기 결과 복사에 드는 O(RC)입니다.

```python
def solution(board, operations):
  result = [row[:] for row in board]

  for top, left, size, d in operations:
    mid = size // 2
    steps = (d // 45) % 8

    for _ in range(steps):
      before = [row[left:left + size]
                for row in result[top:top + size]]
      for i in range(size):
        result[top + i][left + mid] = before[i][i]
        result[top + i][left + size - 1 - i] = before[i][mid]
        result[top + mid][left + size - 1 - i] = before[i][size - 1 - i]
        result[top + i][left + i] = before[mid][i]

  return result
```
