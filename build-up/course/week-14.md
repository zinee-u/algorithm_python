## 2027-01-11 · 기본 기술

### 한 칸 또는 두 칸 오르기

0번에서 n번 계단까지 한 번에 1칸 또는 2칸 오르는 방법 수를 반환하세요. 이동 순서가 다르면 다른 방법입니다. n=0이면 이동하지 않는 한 가지입니다.

- 0 ≤ n ≤ 50

```python
def solution(n):
  pass
```

| 함수 인자 (순서대로) | 결과 |
|---|---|
| `[4]` | `5` |
| `[0]` | `1` |

<details><summary>막혔을 때만: 힌트와 해설</summary>

1. dp[0]=1이 빈 경로를 의미합니다.
2. 작은 n부터 기록을 채웁니다.

n에 오는 마지막 이동은 n-1 또는 n-2에서 시작합니다. 두 경우를 더합니다.

```python
def solution(n):
  dp = [0]*(n+1)
  dp[0] = 1
  for i in range(1,n+1):
    dp[i] = dp[i-1]
    if i >= 2: dp[i] += dp[i-2]
  return dp[n]
```

<details><summary>막혔을 때만: 힌트와 해설</summary>

2. 벽이나 시작 칸은 일반 갱신을 건너뜁니다.

```python
def solution(board):
  N,M = len(board),len(board[0])
  dp = [[0]*M for _ in range(N)]
  if board[0][0]: return 0
  dp[0][0] = 1
  for r in range(N):
    for c in range(M):
      if board[r][c] or (r == 0 and c == 0): continue
      if r > 0: dp[r][c] += dp[r-1][c]
      if c > 0: dp[r][c] += dp[r][c-1]
  return dp[-1][-1]
```

## 2027-01-14 · 기본 기술

### 삼각 전시대의 점수 경로

전시대가 삼각형으로 배치되어 있고 각 칸에는 양수, 0 또는 음수 점수가 적혀 있습니다. 맨 위 triangle[0][0]에서 시작하여 마지막 행까지 내려가야 합니다. 현재 위치가 (r, c)이면 다음 행의 (r+1, c) 또는 (r+1, c+1)로만 이동할 수 있습니다. 한 행도 건너뛰거나 중간에 멈출 수 없습니다. solution(triangle)는 시작 칸과 마지막 칸을 포함해 방문한 모든 칸의 점수를 더한 값의 최댓값을 정수로 반환하세요.

- 1 ≤ 행 수 ≤ 100입니다.
- 0부터 센 r번 행에는 정확히 r+1개의 정수가 있습니다.
- 각 점수는 -1,000 이상 1,000 이하입니다.
- 반드시 첫 행에서 마지막 행까지 이동합니다. 행이 하나이면 그 칸의 점수가 답입니다.

```python
def solution(triangle):
  pass
```

| 함수 인자 (순서대로) | 결과 |
|---|---|
| `[[[3],[4,1],[-2,6,5],[2,-3,4,1]]]` | `17` |
| `[[[-5],[-2,-8],[-6,-1,-3]]]` | `-8` |

<details><summary>막혔을 때만: 힌트와 해설</summary>

1. 현재 보이는 두 점수 중 큰 것을 고르는 선택이 미래까지 최선일까요? 어떤 칸에서 출발해 마지막 행까지 얻을 수 있는 최대 합을 생각해 보세요.
2. 한 칸에서 시작하는 최대 합은 그 칸의 점수에 두 자식 칸에서 시작하는 최대 합 중 큰 값을 더한 것입니다. 마지막 행은 그 칸의 점수 자체로 시작할 수 있습니다.
3. 마지막 행을 best로 복사하고 위쪽 행을 역순으로 처리하세요. 새 best[c]를 triangle[r][c] + max(기존 best[c], 기존 best[c+1])로 계산하면 마지막에 best[0]이 답입니다.

마지막 행의 각 칸에서는 더 내려가지 않으므로 최대 합이 그 칸의 점수입니다. 한 행 위의 칸은 다음 두 칸 중 하나로 반드시 이동하므로, 이미 구한 두 칸의 최대 합 중 큰 값에 현재 점수를 더하면 됩니다. 이 과정을 맨 위까지 반복합니다. 마지막 행의 실제 점수로 초기화하므로 전부 음수인 경우도 처리됩니다. 행 수를 n이라 하면 전체 칸 수에 비례하는 O(n²) 시간이 필요하고, 한 행의 결과만 유지하므로 추가 공간은 O(n)입니다.

```python
def solution(triangle):
  best = triangle[-1][:]
  for r in range(len(triangle) - 2, -1, -1):
    best = [
      triangle[r][c] + max(best[c], best[c + 1])
      for c in range(len(triangle[r]))
    ]
  return best[0]
```

## 2027-01-16 · 토요일 응용

### 차단된 전시장 통과 점수

전시장 지도의 왼쪽 위 칸에서 출발해 오른쪽 아래 칸에 도착해야 합니다. 정수는 칸의 점수이며 음수도 가능합니다. None인 칸은 차단되어 들어갈 수 없습니다. 현재 칸에서 바로 오른쪽 또는 바로 아래 칸으로만 한 칸씩 이동하며, 대각선 이동·역방향 이동·지도 밖 이동은 허용하지 않습니다. solution(grid)는 시작 칸과 도착 칸을 포함한 경로 점수 합의 최댓값을 정수로 반환하세요. 도착할 수 없다면 Python의 None을 반환하세요. 출발 칸이나 도착 칸이 차단된 경우에도 None을 반환합니다.

- 1 ≤ 행 수, 열 수 ≤ 100이며 모든 행의 길이는 같습니다.
- 각 원소는 None 또는 -1,000 이상 1,000 이하의 정수입니다.
- JSON에서 null로 보이는 값은 함수 실행 시 Python의 None으로 전달됩니다. 반환값 None도 JSON에서는 null로 표시됩니다.
- 시작부터 도착까지 반드시 이어진 경로를 완성해야 하며, 중간에 멈추거나 칸을 건너뛸 수 없습니다.
- 지도가 한 칸이고 차단되지 않았다면 해당 칸의 점수를 한 번만 더합니다.

```python
def solution(grid):
  pass
```

| 함수 인자 (순서대로) | 결과 |
|---|---|
| `[[[2,4,-3],[1,null,5],[6,2,1]]]` | `12` |
| `[[[1,null,3],[2,null,4],[null,5,6]]]` | `null` |

<details><summary>막혔을 때만: 힌트와 해설</summary>

1. 어떤 칸에 들어오는 마지막 이동은 위쪽 또는 왼쪽에서 옵니다. 그 두 칸까지의 최적 결과를 알고 있다면 현재 칸의 결과를 정할 수 있습니다.
2. 최대 점수와 도달 불가능 상태를 구별해야 합니다. 점수가 음수일 수 있으므로 0을 도달 불가능의 표시로 사용하면 안 됩니다.
3. DP 배열을 None으로 초기화하고 시작 칸만 별도로 처리하세요. 차단된 칸은 건너뛰고, 위·왼쪽 중 None이 아닌 결과가 있으면 그 최댓값에 현재 점수를 더합니다. 마지막 칸의 DP 값을 반환합니다.

best[r][c]를 시작점에서 (r, c)까지 실제로 도달하는 경로 중 최대 점수로 정의하며, 도달할 수 없으면 None으로 둡니다. 각 칸으로 들어오는 마지막 이동은 위 또는 왼쪽에서만 올 수 있습니다. 위·왼쪽의 도달 가능한 결과가 하나라도 있으면 그중 최댓값에 현재 점수를 더하고, 없으면 None을 유지합니다. 차단된 칸도 None을 유지합니다. 행을 위에서 아래로, 열을 왼쪽에서 오른쪽으로 처리하면 필요한 이전 결과가 이미 계산되어 있습니다. 출발 칸을 별도로 초기화하고 None과 음수를 구분하는 것이 핵심입니다. 시간과 공간 복잡도는 모두 O(행 수 × 열 수)입니다.

```python
def solution(grid):
  rows, cols = len(grid), len(grid[0])
  best = [[None] * cols for _ in range(rows)]
  for r in range(rows):
    for c in range(cols):
      if grid[r][c] is None:
        continue
      if r == 0 and c == 0:
        best[r][c] = grid[r][c]
        continue
      candidates = []
      if r > 0 and best[r - 1][c] is not None:
        candidates.append(best[r - 1][c])
      if c > 0 and best[r][c - 1] is not None:
        candidates.append(best[r][c - 1])
      if candidates:
        best[r][c] = max(candidates) + grid[r][c]
  return best[-1][-1]
```
