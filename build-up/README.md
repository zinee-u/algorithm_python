## 매일 30분

- 월~목: 기억에서 꺼내기 5분 → 작은 기술 3분 → 구현 17분 → 회고 5분.
- 금: 정답을 가리고 같은 기술을 새 코드로 재현합니다. 기억이 안 나면 힌트 한 단계만 봅니다.
- 토/일: 복습 5분 → 평일 기술을 연결한 문제 20분 → 회고 5분.
- 30분은 학습 종료 기준입니다. 어려운 문제를 반드시 완성해야 하는 제한이 아닙니다. 못 풀면 막힌 줄·상태를 남기고 다음에 이어갑니다.
- 쉬었다면 오늘 문제 또는 최근 미완료 한 문제를 고릅니다. 밀린 날짜를 전부 채우지 않습니다.
- 8분 동안 진전이 없으면 첫 힌트, 그래도 막히면 해설을 보고 자신의 말로 한 줄을 적습니다. 다음 재현일에는 해설을 가립니다.

### 회고 양식

1. 이 문제에서 상태는 무엇인가?
2. 어떤 두 개념을 섞었는가? 없다면 왜 이 풀이가 맞는가?
3. 다음에는 무엇을 먼저 확인할까?

각 주 핵심 질문은 첫 학습 다음 날부터 **1 → 3 → 7 → 14 → 30일 간격**으로 다시 나옵니다. 기억이 안 나면 다음 날로 돌아옵니다. 하루 최대 두 카드/5분입니다. 주말 변형 문제와 금요일 재현으로 코드에서도 기억을 확인합니다.
이 간격은 시작 설정이며 개인에게 최적인 간격이나 장기 기억을 보장하지 않습니다. 계속 막히는 문제는 작은 기술로 돌아가 힌트를 줄여 갑니다.

## 보상

- 코드 시도+10자 이상 회고: **15 XP** (오답도 인정)
- 전체 검사 통과: **+10 XP**
- 힌트·해설 없이 해결: **+5 XP**
- 복습 카드: **각 5 XP**, 하루 두 개까지
- 하루 최대 40 XP. 같은 기록 반복 저장으로 점수가 늘어나지 않습니다.
- 성장 단계: 씨앗(0) → 새싹(300) → 작은 나무(900) → 튼튼한 나무(1800) → 큰 나무(3000) → 숲 지기(4500).
- 첫 시도, 쉬었다 돌아오기, 7일 중 5일 학습, 복습 10회, 주말 독립 해결, 누적 30/60/100일 배지.
- 누적 XP와 획득한 배지는 쉬는 날에도 사라지지 않습니다. 연속 일수와 별개로 누적 성장에 보상합니다.

## GitHub 기록

앱에서 코드와 회고를 저장하면 전체 검사를 다시 실행하고 계정별 서버에 저장합니다. GitHub 업로드가 켜져 있으면 이 공개 저장소의 **main** 브랜치에 실제 코드·회고·결과를 커밋합니다. 복습 카드 저장도 업로드 대상입니다.

`records/YYYY-MM/YYYY-MM-DD/`에 날짜별 README, JSON 기록, 직접 작성한 Python 코드를 남깁니다. 원래 문제 날짜와 실제 학습 날짜를 구분하며, 과거 날짜로 커밋하지 않습니다. GitHub 연결이 실패해도 서버 기록은 남고 다시 업로드할 수 있습니다.

정답이 아닌 시도도 기록합니다. 첫 과정 설치 커밋은 학습 완료로 세지 않습니다. 자동 빈 커밋이나 가짜 출석을 만들지 않습니다. GitHub의 프로필 반영에는 기본 브랜치·계정 이메일 연결 등의 조건과 처리 시간이 적용됩니다.
